# Documentação do portfólio

Esta pasta guarda as decisões, planos e referências usados para evoluir o portfólio do Anderson Faria.

## Arquivos principais

- [portfolio-strategy.md](portfolio-strategy.md): estratégia consolidada, opinião sobre os documentos recebidos, posicionamento, roadmap e próximos passos.
- [technical-diagnosis.md](technical-diagnosis.md): diagnóstico técnico real do projeto atual, resultado de build/lint, riscos e plano da primeira sprint.
- [ai-assisted-qa-workflow-study.md](ai-assisted-qa-workflow-study.md): estudo técnico sobre o uso de IA assistiva no fluxo de QA, documentação, análise de risco e evolução incremental do portfólio.
- [references/plano_portfolio_codex_anderson.md](references/plano_portfolio_codex_anderson.md): plano original recebido.
- [references/resposta_codex_estrategia_portfolio_anderson.md](references/resposta_codex_estrategia_portfolio_anderson.md): resposta mais recente recebida.

## Como usar

Antes de implementar mudanças grandes no site, consultar primeiro `portfolio-strategy.md`. Ele registra o caminho escolhido, principalmente a decisão de evoluir a stack atual com Vite + React antes de considerar qualquer migração maior.
